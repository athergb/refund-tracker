# Refund Ticket Tracking System

A web application to track refund tickets with expiry notifications.

## Features
- Add refund tickets via form
- Dashboard with statistics
- Expiry notifications (7 days warning)
- Export to Excel/CSV
- Local storage with optional backend

## Setup Instructions

### 1. Quick Start (Frontend Only)
1. Open `frontend/index.html` in browser
2. Start entering tickets
3. View dashboard at `frontend/dashboard.html`

### 2. Full Setup (with Backend)
1. Install Node.js from https://nodejs.org
2. Open terminal in `backend` folder
3. Run: `npm install`
4. Run: `npm start`
5. Open browser to http://localhost:5000
